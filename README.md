### 🏛️ Selected work

- **[Lumières Lausanne](https://github.com/unil-lettres/lumieres-lausanne-2025)** · University of Lausanne
  Main developer of a platform for publishing and editing scholarly data on the Swiss Enlightenment.
  Modernized the legacy codebase to Django 5 and Python 3.13, migrated the database to MySQL 9,
  then shipped the new features the researchers asked for.
  It turns out 18th-century philosophers need a modern stack too.

### 🛠️ Things I build
 
- **[mdrun.nvim](https://github.com/XavierBeheydt/mdrun.nvim)**: run the code blocks of your Markdown files from Neovim, because copy-pasting commands from a README is so 2010
- **[AetherEngine](https://github.com/AIperture-Labs/AetherEngine)**: a lightweight, modular game engine on Vulkan and modern C++. Me vs. Vulkan: Vulkan is winning, for now
- **[mcp-kraken](https://github.com/XavierBeheydt/mcp-kraken)**: an MCP server wrapping the Kraken Spot REST API, so AI assistants can query the markets. Plugging LLMs into real APIs, one server at a time
